# SQL Lab 2 – Secure Banking Data Model & Business Rules

## 📌 Overview
This lab focuses on designing a secure banking database using **MySQL DDL commands, table relationships, and constraints**. The objective is to organize banking data and maintain data integrity in the `BankingDB` database.

## 🎯 Tasks Completed
- Created `Accounts`, `Transactions`, `Branches`, `AccountBranches`, and `Loans` tables
- Modified table structures using `ALTER TABLE`
- Added and modified columns
- Removed unnecessary tables using `DROP TABLE`
- Applied `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `UNIQUE`, and `CHECK` constraints
- Identified entities and their attributes
- Studied one-to-one, one-to-many, and many-to-many relationships
- Generated an Entity Relationship Diagram (ERD) using MySQL Workbench
- Learned database normalization: 1NF, 2NF, and 3NF
